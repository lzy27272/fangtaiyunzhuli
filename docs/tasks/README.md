## 维护规则

1. 每确认一个业务板块，立即更新对应任务文档的“已确认决策”和“对话同步记录”。
2. 未经明确开工批准，任务只能标记为“需求沟通中”或“待开发”，不得写成已实现。
3. 开始编码后，再按项目治理要求同步 `CHANGELOG.md`、技术版本、数据库/API版本及测试证据。
4. 任务涉及账号、Cookie、Token、Webhook或密码时，只记录凭证位置和状态，不记录秘密值。
