## 一、验收目标

确认TECH-V0.2在目标环境中具备可持续运行和可恢复能力，覆盖：

1. 受控部署和可追溯制品。
2. 持久化PostgreSQL、安全运行账号和租户隔离。
3. 目标对象存储、附件安全和生命周期。
4. 数据库及附件的备份、加密、保留和恢复。
5. 健康、容量、业务Worker和安全链路的监控告警。
6. 已批准的RPO、RTO和恢复演练。
7. 应用及数据库变更的回滚/前滚方案。
8. 运维、DBA、安全、QA和发布负责人正式签署。

## 二、证据与安全要求

- 原始证据必须来自目标环境，并标明环境、时间、执行人、命令或平台作业编号和结果。
- 不得在本文中记录数据库密码、云密钥、KMS明文、Webhook Secret或完整访问Token。
- 日志和截图必须脱敏，不得暴露住客、员工或企业敏感数据。
- 所有制品必须核对SHA-256及来源提交/标签；本地无Git来源的RC制品不能直接作为正式部署批准依据。
- 任何恢复或回滚演练必须在批准的隔离范围执行，禁止对未授权生产数据做破坏性试验。
- 实测失败、证据缺失或责任人未签署时，状态保持`BLOCKED`。
