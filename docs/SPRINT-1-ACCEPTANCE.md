# Sprint 1 验收清单

## P0 必须通过

- [x] 可创建多个租户，所有领域数据都带 `tenant_id`。
- [x] 跨租户组织、员工、标准、工作记录和指标访问被拒绝。
- [x] 支持集团→区域→门店→部门的组织树。
- [x] 同一员工可绑定多个岗位并设置主岗、生效和失效时间。
- [x] RBAC 支持角色权限和组织范围。
- [x] 标准支持分类、版本、范围、发布和历史追溯。
- [x] 岗位工作记录关联任职与表单版本。
- [x] 经营指标包含业务日期、来源、数值和审核状态。
- [x] CEO 与店总驾驶舱框架能按身份展示。

## 安全检查

- [x] 客户端不能通过修改请求体覆盖服务端租户上下文。
- [x] 运行数据库账号不拥有 `BYPASSRLS`，也不是业务表所有者。
- [x] 上传只保存受控对象键，禁止把客户端绝对路径写入数据库。
- [x] 标准发布后不可原地修改，必须创建新版本。
- [x] 审计日志记录操作者、租户、动作、对象和关联 ID。
